# Caderno de Pesquisas

Um espaço para reunir minhas pesquisas, estudos, anotações, explicações, testes e descobertas pessoais.

O caderno pode receber conteúdos de tecnologia, ciências, história, sociedade, cotidiano e qualquer outro assunto que eu venha a estudar. As categorias surgem conforme houver pesquisas para organizar.

## Como navegar

Cada tema tem um índice com links para suas pesquisas. Sistemas de arquivos fica dentro de Computador. As notas permanecem em Markdown; imagens e outros materiais de apoio acompanham os documentos.

Os índices identificam os arquivos ainda vazios como **em desenvolvimento**. Conteúdos recuperados de versões antigas estão identificados no índice de Security e no relatório de migração.

## Pesquisas e projetos

Este caderno reúne estudos e experimentos. Projetos que aplicam esses conhecimentos e possuem uma finalidade própria continuam independentes.

Por exemplo: as pesquisas sobre inteligência artificial ficam aqui; o [Agente Letras](https://github.com/kevinoliveiraz/agente-letras), que aplica esse conhecimento em um projeto de escrita, continua em seu próprio repositório.

## Novas pesquisas

Use o [modelo de pesquisa](MODELO-PESQUISA.md) como ponto de partida. Adapte as seções ao assunto: uma pesquisa não precisa ter experimentos ou resultados práticos para fazer parte do caderno.

## Origem dos conteúdos

O [relatório de migração](MIGRACAO.md) registra os repositórios de origem, o histórico preservado, os ajustes de caminhos e as validações realizadas.
