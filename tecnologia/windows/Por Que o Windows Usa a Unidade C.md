# Por Que o Windows Usa a Unidade C:
Muitas pessoas acreditam que todo sistema operacional começa no disco C:.

Na realidade, isso é uma característica do Windows e seus antecessores.

---

# Antes dos Discos Rígidos

Nos primeiros computadores pessoais era comum utilizar disquetes.

O sistema reservava:

```text
A: → Primeiro drive de disquete
B: → Segundo drive de disquete
```

Quando os discos rígidos começaram a ser utilizados, a próxima letra disponível era:

```text
C:
```

---





# Por Que Continua Existindo?

Milhares de programas foram desenvolvidos assumindo que o sistema estaria em:

```text
C:\Windows
```

ou

```text
C:\Program Files
```

Por compatibilidade, a Microsoft manteve esse padrão.

---

# O Disco Precisa Ser C:?

Não.

O Windows pode ser instalado em outras letras.

Exemplo:

```text
D:
E:
F:
```

Porém isso é incomum e pode causar problemas com alguns programas.

---

# Curiosidade

Mesmo em computadores modernos sem leitor de disquete, as letras A: e B: continuam reservadas por compatibilidade histórica.
